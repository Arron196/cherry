# Draw.io Vector Figures

本目录包含：
- 单图 `.drawio` 可编辑源文件
- 单图 `.svg` 矢量导出
- 多页总文件 `traceability_figures.drawio`

这版重画强调 draw.io 的原生优势：
- 容器 / 泳道 / 决策菱形 / 数据库存储 / 云端 / 浏览器线框图
- 正交连线、分区布局、阶段式表达
- 更适合论文中流程图、架构图、拓扑图、站点地图的版式
